# First examples first

- A greenfield repo has no neighbor to copy. The first instance of each pattern to copy is a die, not just a feature.
- Build the first module, route, form, system, or command supervised, with care.
- Record each in the AGENTS.md First examples table: pattern → path → what it shows.
- Until neighbors exist, every plan and rule that needs a pattern must point at a first-example path.
- Encode folder rules in the structure check the same week the first example lands so the second instance cannot drift.
- When a sub-pattern repeats (for example a new interaction contract), mint a First examples row the week it ships. The second instance copies; it does not invent.
- First lessons often come from correcting those builds.
